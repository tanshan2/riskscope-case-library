# 险知 · 企业风险案例库

帮助企业主通过日常关键词找到真实事件、相关风险与可能需要讨论的保险。当前版本收录 **50 个公开真实案例、16 类保险指南**。

**公开访问：[打开案例库](https://riskscope-case-library.tant25395.chatgpt.site/)**

## 功能

- 搜索公司、CEO、CFO、董事及日常风险描述，例如“财报出错”“员工告我”“假冒老板转账”“厂房着火”“客户不付款”。
- 按风险类别、相关险种、角色、地区及保险证据筛选，查看同类案例。
- 案例详情提供事实、相关保险、保障边界、企业行动与原始来源。
- 最多对比 3 个案例；收藏及导出讨论清单。收藏只保存在当前浏览器。

## 保险范围

董事及高管责任、网络安全、专业责任、商业犯罪、雇佣行为责任、产品责任、产品召回、企业财产、营业中断、货运与海事、工程、环境污染、并购保证、关键人物、贸易信用、公众责任。

## 本地运行

需要 Node.js 18 或更新版本，无第三方运行依赖。

~~~sh
npm start
~~~

访问 http://127.0.0.1:4180 。也可直接用浏览器打开 index.html。

~~~sh
npm test
npm run build
~~~

build 更新扩展案例数据。GitHub Pages 选择 main 分支的 /(root) 目录发布。修改内容后应先运行构建与测试，再提交全部变更。

## 文件

- index.html、style.css、expansion.css、app.js、engine.js：网站界面与搜索。
- data.js：首批 20 个案例及基础指南。
- expanded-data.js：其余 30 个案例及扩展指南，由 expand-data.cjs 生成。
- operations.json、employment-product.json、transaction-person.json、guides.json：用于继续维护的结构化公开资料。
- search.test.cjs、expansion.test.cjs、validate.cjs：搜索行为、数据完整性与保障表述检查。

## 内容口径

核对日期：2026-10-22。每条案例附公开原始来源；收录的是来源支持的事件节点，不代表已追踪全部后续程序，内容不会自动更新。

风险事件、承保争议、预期保险回收和保险人付款安排分别标注。监管罚款、企业损失与保险赔款不能混用。相关险种与保障边界为风险教育分析，不构成个别承保、理赔或法律结论；具体须核对适用法律和保单条款。

原始会议转写、私人附件、账户凭证及托管配置没有包含在此仓库中。网站没有登录后台或服务器数据库。
